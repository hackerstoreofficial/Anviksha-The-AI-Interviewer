Groq

Ultra-fast inference

  1. Visit console.groq.com/keys

  3. Click "Create API Key"
  4. Name your key (e.g., anviksha), then copy it
💡 Groq offers a generous free tier — great for getting started with no payment method required.

OpenAI

GPT-3.5 / GPT-4

  2. Log in or create an OpenAI account
  3. Click "Create new secret key"

🛡️ Important tips for your API key

🔒

Your key stays local

Anviksha stores your API key in your browser's session storage. It's never sent to our servers or saved permanently.

🚫

Never share your key

Treat your API key like a password. Don't post it publicly or share it with others.

💰

Set usage limits

Most providers let you set monthly spending caps. Enable this to avoid unexpected charges.

🔄

Rotate keys periodically

For best security, regenerate your API key every few months and revoke old ones.

Common Questions

Frequently Asked Questions

Which provider should I choose? ›
If you're just getting started, Groq is recommended — it's fast, free, and requires no payment setup. For advanced models, OpenAI (GPT-4) or Google Gemini are excellent choices.
Is my API key safe with Anviksha? ›
Yes. Your key is stored only in your browser's session storage and is cleared when you close the tab. On the backend, keys are encrypted at rest using Fernet symmetric encryption. We never log or persist your raw key.
How much does it cost to run an interview? ›
A typical 15-minute interview session uses approximately 2,000–5,000 tokens. With Groq's free tier, this costs nothing. With OpenAI GPT-4, it's roughly $0.05–$0.15 per session depending on response length.
My API key isn't working — what should I do? ›
Double-check that you've selected the correct provider in the dropdown. Make sure the key is copied in full (no trailing spaces). If the issue persists, try generating a fresh key from your provider's dashboard.
Can I switch providers between sessions? ›
Absolutely. Each session lets you pick a different provider and API key on the System Setup page. There's no lock-in.
